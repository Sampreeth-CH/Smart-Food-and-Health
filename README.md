# 🥗 SmartFood & Health AI

An intelligent web application that helps users **analyze food, track nutrition, and improve health** using AI-powered insights.

---

## 🚀 Features

- 🔍 **AI Food Analysis**  
  Analyze food items and get detailed nutritional insights.

- 📊 **Health Score System**  
  Calculates a health score based on nutritional value.

- 🧠 **Smart Recommendations**  
  AI suggests healthier food alternatives.

- 📝 **Manual Food Entry**  
  Add and manage your own food items.

- 🌐 **Multi-Language Support**  
  Supports multiple languages (Kannada, Hindi, Tamil, Telugu, etc.)

- 📱 **Responsive UI**  
  Works seamlessly across devices.
